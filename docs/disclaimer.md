# Disclaimer

This project is strictly for **educational and research purposes only**.

## What this tool does NOT do

- ❌ Validate phone numbers or emails against private services
- ❌ Reliably confirm the ownership of a phone number or email
- ❌ Access external systems without authorization
- ❌ Perform scraping, credential validation, or unauthorized lookup
- ❌ Guarantee accuracy of third-party data

## What this tool DOES do

- ✅ Generate password combinations from user-provided data
- ✅ Validate email format locally
- ✅ Validate phone format using `phonenumbers`
- ✅ Query the public "Have I Been Pwned" API in read-only mode
- ✅ Support security research and authorized testing
